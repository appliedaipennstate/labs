Put your card on the Labs wall

Three steps. Your AI agent does the work, and you'll see how a real software team adds a change to a shared project.

  1. 1

    Open your workspace

    This opens a Codespace: a coding workspace in your browser with the club's project and GitHub Copilot ready to go.

    Open my Codespace

    Sign in to GitHub if it asks. It takes about a minute to start.

  2. 2

    Ask your agent

    If a box asks whether you trust the files, click Trust Folder & Continue. Then, in the Copilot chat on the right (it should say Agent), send this:

    Make my Labs card

    Copilot will ask you three questions and write your card. Each time it wants to run a command, it will tell you what the command does. Read it, then click Allow. When it edits your card, click Keep.

  3. 3

    Watch the wall

    When Copilot says your pull request is open, the club's review bot checks your card. About a minute later, it shows up below.

Copilot not working?

In your Codespace, click in the terminal at the bottom and type labs new. Open the card it makes, fill in the three lines, then type labs submit.

What's actually happening

An agent
A model plus tools, working in a loop. It reads where things stand, picks the next step, uses a tool like the terminal, checks what came back, and repeats until the job is done. That loop is the difference between chatting with an AI and having one do the work.
The model
The part that does the thinking. Copilot can use models from several companies, such as OpenAI, Anthropic, Google, and Microsoft. The name under each reply in the chat is the model that wrote it.
Commands
Typed instructions the computer runs exactly. Agents use them because they're precise and repeatable, and the output tells the agent what happened. labs is a small program the club wrote for tonight.
GitHub
Where millions of software projects live. It keeps every version of every file and lets people propose and review changes. Your card is your first contribution to a project on it.
A pull request
How you ask a project you don't own to accept your change. The club's review bot checks your card, then merges it in.
