# Welcome to Applied AI Labs

You're inside a Codespace: a coding workspace that runs in your browser. Nothing gets installed on your laptop.

## Tonight: put your card on the Labs wall

1. If a box asks "Do you trust the authors of the files in this folder?", click Trust Folder & Continue. This is the club's project.
2. Find the Copilot chat on the right. If it isn't open, click the chat icon at the top of the window. It should say Agent under the message box.
3. Send this: Make my Labs card

Copilot will ask you three questions, write your card, and send it to the club. Each time it wants to run a command, it tells you what the command does. Read it, then click Allow. When it edits your card, click Keep.

Watch your card show up: https://labs.appliedaipennstate.com/wall/

## What's actually happening tonight

- GitHub: where millions of software projects live. It keeps every version of every file and lets people propose and review changes to a project.
- Repository: a project's folder on GitHub, plus the history of every change ever made to it. This one belongs to the club.
- Codespace: the workspace you're in right now. A computer in the cloud with the project already on it.
- Terminal and commands: the panel at the bottom of the window. You type a command, the computer runs it and prints what happened. `labs` is a small program the club wrote for tonight.
- Model: the AI that does the thinking. Copilot can use models from several companies, such as OpenAI, Anthropic, Google, and Microsoft. The name under each reply is the model that wrote it.
- Agent: a model plus tools, working in a loop. It reads where things stand, picks the next step, uses a tool like the terminal, checks what came back, and repeats until the job is done. It asks you before each command because it's acting on a real computer.
- Pull request: how you ask a project you don't own to accept your change. The change gets reviewed, then merged in.

## If Copilot isn't working

Click in the terminal at the bottom of the window and type:

    labs new

Open the card it makes in the `members` folder, replace the three parts in [square brackets], and save. Then type:

    labs submit
